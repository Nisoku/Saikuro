Saikuro math example

One math provider and one client, built from math-core for the browser.

In-memory

Provider and client in this page, over in-process MPSC channels. Runs on load.

In-realm (BroadcastChannel)

Provider and client in two same-origin contexts, over a BroadcastChannel rendezvous. Open this page in a second tab and provide on the same channel, then dial. Tab order does not matter btw as the client half re-announces until the accept lands.

WebSocket

Client-only: dial a ws:// or wss:// provider running elsewhere, for example cargo run -p math -- --transport ws --addr 127.0.0.1:9000 --serve-only. A browser cannot serve WebSocket connections.
